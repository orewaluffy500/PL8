PL8 assembly is very simple.


There are registers 0 to 128 (129 registers in total).
Allocations are basically arrays and you store their addresses not the allocation itself.

<( ESCAPE CODES )>

\n: newline
\t: tab
\q: quote (only works for strings)
\a: apostrophe (only works for char literals)
\\: normal backslash, for strings you can also just use the normal one, but for characters use this.

<( GRAMMAR DEFINITIONS )>

[register]      : an index of a register, prefixed with a dot
                ex. - ".12", ".6"

[constant]      : a int constant, it can also be a character which just gets turned into it's ASCII value
                ex. - 123, 'A'

"[string]"      : a string constant
                ex. - "hello", "bye"

[value]         : either a [constant] or a [register]

[identifier]    : the name of a label or others.

<( INSTRUCTIONS )>

mov [register], [value]         : set a register
incr [register]                 : increment a register
decr [register]                 : decrement a register

jmp [identifier]                : jump to a label
call [identifier]               : jump to a label and push pc onto stack
ret                             : pop the top pc off the call stack and return to it

jz [identifier], [value]        : jump to a label if [value] is zero
jnz [identifier], [value]       : jump to a label if [value] isn't zero

cmp [value], [value]            : compare two values and store results
je [identifier]                 : jump to a label if comparison result in equality
jne [identifier]                : jump to a label if comparison result in non-equality
jg [identifier]                 : jump to a label if comparison result in greater
jge [identifier]                : jump to a label if comparison result in greater or equal
jl [identifier]                 : jump to a label if comparison result in less
jle [identifier]                : jump to a label if comparison result in less or equal

add [index], [value], [value]   : add two values and put result in [index]
sub [index], [value], [value]   : subtract two values and put result in [index]
mul [index], [value], [value]   : multiply two values and put result in [index]
div [index], [value], [value]   : divide two values and put result in [index]
pow [index], [value], [value]   : power two values and put result in [index]

allc [index], [value1]          : allocate [value] amount of space and put the address in [index]
setx [value], [value1], [value2]: set an element of an allocation, [value] is the address
getx [value], [value1], [index] : get the element of an allocation into [index], [value] is the address
fill [value], [value1]          : fill an allocation with a value, [value] is the address
str [value], "[string]"         : expands into `setx` instructions that set each element of the allocation who's address is in [value]
                                to each character of the given string.
                                very useful.

label [identifier]              : define a label

hlt                             : halt the program immediately
nop                             : does nothing, can be used as padding in the machine code



<( SYSCALLS )>

256 : print the word "soup"

257 : print r128 as an integer

258 : print r128 as an ASCII character

259 : print the allocation who's address is stored in r128 as a string (each element is an ASCII char)

260 : take the allocation who's address is stored in r128, measure it's length as a string and load that into r128

512 : read an integer

513 : read an ASCII character

514 : read a string into the allocation who's address is stored in r128
