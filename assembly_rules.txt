PL8 assembly is very simple.


There are registers 0 to 128 (129 registers in total).
Allocations are basically arrays and you store their addresses not the allocation itself.

<( ESCAPE CODES )>

\n: newline
\t: tab
\q: quote (only works for strings)
\a: apostrophe (only works for char literals)
\\: normal backslash, for strings you can also just use the normal one, but for characters use this.

<( GRAMMAR DEFINITIONS )>

[register]      : an index of a register, prefixed with a dot
                ex. - ".12", ".6"

[constant]      : a int constant, it can also be a character which just gets turned into it's ASCII value
                ex. - 123, 'A'

"[string]"      : a string constant
                ex. - "hello", "bye"
            
[accum]         : a '$' character, represents the current value in the accumulator

[value]         : either a [constant] or a [register] or an [accum]

[identifier]    : the name of a label or others.

<( INSTRUCTIONS )>

mov [register], [value]      : set a register
dup [register], [register]      : duplicate value of 1st register to 2nd register
incr [register]                 : increment a register
decr [register]                 : decrement a register

load [value]                    : load a value into the accumulator

jmp [identifier]                : jump to a label
call [identifier]               : jump to a label and push pc onto stack
ret                             : pop the top pc off the call stack and return to it

jz [identifier]                 : jump to a label if accum is zero
jnz [identifier]                : jump to a label if accum isn't zero

cmp [value], [value]            : compare two values and store results
je [identifier]                 : jump to a label if comparison result in equality
jne [identifier]                : jump to a label if comparison result in non-equality
jg [identifier]                 : jump to a label if comparison result in greater
jge [identifier]                : jump to a label if comparison result in greater or equal
jl [identifier]                 : jump to a label if comparison result in less
jle [identifier]                : jump to a label if comparison result in less or equal

add [value], [value]            : add two values and put result in accumulator
sub [value], [value]            : subtract two values and put result in accumulator
mul [value], [value]            : multiply two values and put result in accumulator
div [value], [value]            : divide two values and put result in accumulator
pow [value], [value]            : power two values and put result in accumulator

allc [value]                    : allocate [value] amount of space and put the address in accumulator
setx [value], [value]           : set an element of an allocation, accumulator is the address
getx [value]                    : get the element of an allocation back into the accumulator, accumulator is the address
fill [value]                    : fill an allocation with a value, accumulator is the address
str "[string]"                  : expands into `setx` instructions that set each element of the currently loaded allocation (in accum) 
                                to each character of the given string.
                                very useful.

label [identifier]              : define a label

hlt                             : halt the program immediately
nop                             : does nothing, can be used as padding in the machine code



<( SYSCALLS )>

256 : print the word "soup"

257 : print the accumulator as an integer

258 : print the accumulator as an ASCII character

259 : print the allocation who's address is stored in the accumulator as a string (each element is an ASCII char)

260 : take the allocation who's address is stored in the accumulator, measure it's length as a string and load that into the accumulator

512 : read an integer

513 : read an ASCII character

514 : read a string into the allocation who's address is stored in the accumulator


<( EXAMPLE: Greeter )>

This example reads a string, stores it, prints a temporary string ("hello, ") and then prints the previous string which was the name.

```
label _main_
    allc 64
    syscall 514     ; read the name
    mov .0, $       ; store the string address in register 0

    allc 32
    str "hello, "   ; make a new string
    syscall 259     ; print it

    ; we'll override the accumulator (which currently holds address for greet string)
    ; since we don't need to store the greeting string. ("hello, ")
    load .0

    ; now print the name
    syscall 259

    ; and finally we'll print a newline
    load 10         ; line feed ASCII code
    syscall 258     ; print as ASCII

label _exit_
    hlt
```

--  Output  --
jack
hello, jack
